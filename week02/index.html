Why these L values?

OKLCH L runs from 0 (black) to 1 (white) and is perceptually uniform, so a large gap is a strong starting point: 0.97 − 0.22 = 0.75 in light mode and 0.94 − 0.18 = 0.76 in dark mode.

WCAG does not calculate contrast from that L gap directly. After converting each color to linear sRGB, it uses (Llighter + 0.05) / (Ldarker + 0.05). These pairs produce 15.89:1 and 15.79:1—well above AA’s 4.5:1 requirement for normal text.

02 / Calculating fluid scales

Type that finds
its own line.

Resize the viewport

Streets are the studio.

375px / 1.75rem 1440px / 3rem

Production value

--title-size: clamp(1.75rem, 1.3099rem + 1.8779vw, 3rem);
  1. 01

    Convert the endpoints

    At a 16px root size: 1.75rem = 28px and 3rem = 48px.

  2. 02

    Find the slope

    (48 − 28) ÷ (1440 − 375) = 0.018779px per viewport pixel. Multiply by 100 to express it as 1.8779vw.

  3. 03

    Find the intercept

    28 − (0.018779 × 375) = 20.9577px. Divide by 16 to get 1.3099rem.
